CodeOrbit Tech – Python Projects

This repository contains Python projects developed as part of my Python Programming internship practice.

Projects

1. Simple Calculator

- Performs addition, subtraction, multiplication, and division.
- Handles invalid inputs and division by zero.

2. To-Do List CLI App

- Add tasks.
- View tasks.
- Remove tasks.
- Menu-based command-line interface.

3. Student Grade Calculator

- Accepts student name and subject marks.
- Calculates total marks and percentage.
- Displays the grade.

Technologies Used

- Python
- Visual Studio Code

Author

Python Programming Intern

Setup Instructions

1. Install Python 3 on your computer.

2. Download or clone this repository.

3. Open the project folder in Visual Studio Code.

4. Open a terminal in the project folder.

5. Run the required Python file:
   
   - Calculator: "python calculator.py"
   - To-Do List: "python todo.py"
   - Grade Calculator: "python grade_calculator.py"
